# SiliconPulse AI — Always-on live demo

This folder is a **fully browser-based** demo:

- No terminal
- No Docker
- No Python server
- Real-time fleet updates while the page is open

GitHub Pages serves these static files as a public URL.

The page also exposes three synthetic, auditable semiconductor-AI modules:

- lifecycle survival/RUL assessment;
- wafer spatial-signature and yield triage;
- evidence-grounded engineering copilot output with approval boundaries.

The browser views are explanatory companions to the reproducible Python implementations and committed artifacts. They do not represent production semiconductor validation.
